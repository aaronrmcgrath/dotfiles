# /learn

Capture and organize technical learnings from this session.

## Steps

1. Review what was worked on in this session (ask if unclear).
2. Identify non-obvious learnings: root causes, architectural decisions, surprises, patterns.
3. Delegate to the `learning-notes` agent to produce a structured note.
4. Ask: "Should I save this to `~/.ai/` or a project-specific location?"
5. Write the note to the appropriate location.

## When to use

- After a complex debugging session
- After making a significant architectural decision
- After exploring a new tool or API
- After any session where you learned something worth not forgetting

## Output

A structured learning note in the format defined by the `learning-notes` agent.
